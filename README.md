# 可复现实验模板（阶段 1 教具）

一次实验必须满足四条，才算「可复现」：

1. 参数不在代码里，在 `configs/` 的 YAML 里
2. 随机种子写进配置并固定
3. 一次实验一条命令：`bash run.sh`
4. 结果落到 `results/`，日志落到 `logs/`，两者都不进版本库

目录约定：
- `configs/` 参数快照（每次实验复制一份，带日期）
- `src/` 代码
- `tests/` 最小自测
- `results/` 指标与产物（被 .gitignore 忽略）
- `logs/` 运行日志（被 .gitignore 忽略）

判据：连跑两次 `bash run.sh`，两次 `results/metrics.json` 内容完全一致（时间戳字段除外）。

## 网格实验：为什么不能只跑一次

`scripts/sweep.py` 跑「参数档位 × 随机种子」的网格，输出分布而不是单点。

```bash
python scripts/sweep.py --noise 0.10,0.20,0.30 --seeds 1,2,3,4,5
```

它会打印三样东西：

1. **可复现性**：同配置同种子跑两次，数字必须按位相同
2. **分布**：同一档参数、不同种子下的均值/标准差/极差
3. **信噪比**：均值差 ÷ 组内波动。< 2 就不该把差异写进结论

实测（见 `stage1-engineering/lesson04-reproducible-experiment.md`）：

| noise_std | 均值 | 标准差 | 极差 |
|---|---|---|---|
| 0.10 | 0.544 | 1.311 | 3.550 |
| 0.20 | 1.089 | 2.622 | 7.099 |

**同一档参数下，只换种子，极差就有 3.5。** 而两档之间的均值差只有 0.54——
信噪比 0.28，说明这组样本根本不足以支持结论。

> 单次运行给你的不是「这个参数的表现」，是「这一次抽签的结果」。
> 原始数据落在 `results/sweep.csv`（已被 `.gitignore` 排除：能一键重跑的东西不入库）。
